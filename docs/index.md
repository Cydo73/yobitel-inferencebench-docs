# InferenceBench documentation

This is an independent documentation set for InferenceBench, the open inference benchmark and cost tool run by Yobitel. It was written by Mumpe Cydrone and is not official.

Every procedure here was run on 2026-10-23 and recorded in the [verification log](verification_log.md). Each page opens with a status line:

* **Verified:** I ran it and checked the result.
* **Partly verified:** some steps or values were recorded, others were not.
* **Draft:** not tested yet.

The set follows the Diataxis structure, which keeps four kinds of writing apart.

| You want to | Read |
| --- | --- |
| Learn by doing | [Tutorial](tutorial.md) |
| Complete one task | [How to share a configuration](how_to_share_configuration.md) |
| Look up a fact | [Reference](reference.md) |
| Understand why | [Explanation](explanation.md) |

There is also a short [audit](audit.md) of places where the product pages and the tools disagree, with suggested fixes.
